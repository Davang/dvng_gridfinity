# dvng_gridfinity

Based on gridfinity by [Zack Freedman's]([Gridfinity | The modular, open-source grid storage system.](https://gridfinity.xyz/specification/)). As it is an open design I belive it shall be possible to use only open too. That is why I created this repository.

There is a single freecad file with all paramters, and bodies. There is one for the base plate that may be adjusted to any grid size.



Check [the especification]([Gridfinity | The modular, open-source grid storage system.](https://gridfinity.xyz/specification/)) to know more about the design. I may not have strictly followed it. So I can ensure compatibility with original design.
